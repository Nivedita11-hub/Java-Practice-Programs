## Repository organization

Each topic contains a dated subfolder. Future batches will be added under their corresponding topics while retaining their original practice-session labels.

## How to run a program

Install a JDK, open a terminal in the directory containing the `.java` file, and run:

```bash
javac FileName.java
java FileName
```

Replace `FileName` with the class/file name without `.java`. Compile and run one independent practice program at a time.
